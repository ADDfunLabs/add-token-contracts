# Security

For security reports, privately contact the official team via [Telegram](https://t.me/ADD_FU) or [X](https://x.com/ADDfunLabs). Do not publish private keys, access credentials or an unpatched exploit in a public issue.

This archive preserves deployed implementation snapshots. Updating repository files does not update deployed contracts or existing tokens. New implementations must be published as new snapshots with their own addresses and reproducible evidence.

No independent audit certification or bounty commitment is implied by this repository.
